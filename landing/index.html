How it works

  1. Create an account

    Sign up as a student or as an instructor.

  2. Enroll and learn

    Open lessons in any order and mark each one complete.

  3. Take the quiz

    Answers are checked on the server and your best score is saved.

Cloud architecture

Three tiers, each of which can be scaled or replaced on its own.

Presentation

This HTML, CSS and JavaScript site plus the React single-page app. Can be hosted on a CDN or object storage.

Application

Stateless Node.js and Express REST API with JWT login. Packaged in Docker and run behind a load balancer using /api/health.

Data

JSON file store for the demo. Swap db.js for MongoDB Atlas, Amazon RDS or DynamoDB in production.
